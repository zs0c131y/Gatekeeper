# Master AI-Readable Technical Documentation

## 1. System Overview

This folder contains the single, authoritative, production-grade technical documentation for the Intelligent Adaptive API Gateway. It is designed for automated parsing and analysis by AI agents to ensure a deep and accurate understanding of the system's architecture, features, and implementation.

This system was generated by merging two previous documentation sources:
1.  `AI-DOCS`: Documentation based on direct codebase analysis.
2.  `md-docs-for-ai`: Documentation generated from the Software Requirements Specification (SRS).

## 4. Documentation Rules

*   **Granularity:** Documentation granularity matches code granularity. One file per component, module, or data structure.
*   **Separation of Concerns:** Backend, frontend, and shared concepts are never mixed in the same file.
*   **Format:** All files are in pure Markdown, using headings for structure, tables for structured data, and lists for enumerations. No commentary or conversational text is included.
*   **Authority:** This documentation is the single source of truth.

## 5. Terminology Standard

*   **Gateway:** The central Intelligent Adaptive API Gateway system.
*   **Backend:** The Node.js server application.
*   **Frontend:** The React single-page application (SPA).
*   **Module:** A distinct functional unit within the backend or frontend.
*   **Component:** A reusable UI element in the frontend.
*   **Service:** A backend process providing a specific function via an API.
*   **Trace ID:** A unique identifier for a request, used for tracking across services.
