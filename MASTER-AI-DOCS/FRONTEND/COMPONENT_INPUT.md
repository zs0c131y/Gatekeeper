# Component: Input

## 1. Inputs/Props

| Prop | Type | Description |
| :--- | :--- | :--- |
| `type` | `string` | The `type` attribute of the HTML `<input>` element. |
| `className` | `string` | Additional CSS classes to apply. |
| `...props` | `object` | Other props passed to the underlying `<input>` element. |

## 2. Outputs

Renders a styled HTML `<input>` element.

## 3. Dependencies

*   **External Libs:** `react`.
*   **Internal Utils:** `lib/utils.js`.
