# Component: Checkbox

## 1. Inputs/Props

| Prop | Type | Description |
| :--- | :--- | :--- |
| `...props` | `object` | Props are passed directly to the underlying `@radix-ui/react-checkbox` component. |

## 2. Outputs

Renders a checkbox input with a visual checkmark icon.

## 3. Dependencies

*   **External Libs:** `react`, `@radix-ui/react-checkbox`, `lucide-react`.
*   **Internal Utils:** `lib/utils.js`.
