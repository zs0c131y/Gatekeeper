# Component: Select

## 1. Inputs/Props

This component is composed of several sub-components from `@radix-ui/react-select`: `Select`, `SelectGroup`, `SelectValue`, `SelectTrigger`, `SelectContent`, `SelectLabel`, `SelectItem`, `SelectSeparator`.

## 2. Outputs

Renders a styled, accessible select (dropdown) input.

## 3. Dependencies

*   **External Libs:** `react`, `@radix-ui/react-select`, `lucide-react`.
*   **Internal Utils:** `lib/utils.js`.
