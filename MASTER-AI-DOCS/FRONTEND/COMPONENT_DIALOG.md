# Component: Dialog

## 1. Inputs/Props

This component is composed of several sub-components from `@radix-ui/react-dialog`: `Dialog`, `DialogTrigger`, `DialogContent`, `DialogHeader`, `DialogFooter`, `DialogTitle`, `DialogDescription`.

## 2. Outputs

Renders a modal dialog overlay.

## 3. Dependencies

*   **External Libs:** `react`, `@radix-ui/react-dialog`, `lucide-react`.
*   **Internal Utils:** `lib/utils.js`.
