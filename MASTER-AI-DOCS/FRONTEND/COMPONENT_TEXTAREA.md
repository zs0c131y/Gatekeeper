# Component: Textarea

## 1. Inputs/Props

| Prop | Type | Description |
| :--- | :--- | :--- |
| `className` | `string` | Additional CSS classes to apply. |
| `...props` | `object` | Other props passed to the underlying `<textarea>` element. |

## 2. Outputs

Renders a styled HTML `<textarea>` element.

## 3. Dependencies

*   **External Libs:** `react`.
*   **Internal Utils:** `lib/utils.js`.
