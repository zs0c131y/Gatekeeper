# Data Structures

## 1. MongoDB Collections

| Collection | Description | File |
| :--- | :--- | :--- |
| `users` | Dashboard administrator/viewer user accounts. | `src/models/User.js` |
| `apikeys` | API keys for gateway client authentication. | `src/models/ApiKey.js` |
| `configs` | Dynamic system configuration (rate limits, circuit breaker, security). | `src/models/Config.js` |
| `backends` | Definitions of registered upstream backend services. | `src/models/Backend.js` |
| `routes` | Routing rules mapping gateway paths to backend services. | `src/models/Route.js` |
| `logs` | Log entry for every request processed by the gateway (30-day TTL). | `src/models/Log.js` |
| `analytics` | Aggregated metrics snapshots (minute/hour/day). | `src/models/Analytics.js` |
| `clientprofiles` | Client behavior tracking (IP or API key based). | `src/models/ClientProfile.js` |
| `alerts` | System notifications and alerts. | `src/models/Alert.js` |

## 2. Redis Data Structures

| Key Pattern | Description | Generated By |
| :--- | :--- | :--- |
| `rl:counter:{clientId}` | Token bucket request counter per client. | `redisKeys.rateLimitCounter()` |
| `rl:bucket:{clientId}` | Token bucket state per client. | `redisKeys.rateLimitBucket()` |
| `cb:state:{backendName}` | Circuit breaker state (CLOSED/OPEN/HALF_OPEN). | `redisKeys.circuitState()` |
| `cb:failures:{backendName}` | Consecutive failure counter per backend. | `redisKeys.circuitFailureCount()` |
| `cb:lastfail:{backendName}` | Last failure timestamp per backend. | `redisKeys.circuitLastFailure()` |
| `health:score:{backendName}` | Health score (0-100) per backend. | `redisKeys.healthScore()` |
| `health:lastcheck:{backendName}` | Last health check timestamp per backend. | `redisKeys.healthLastCheck()` |
| `metrics:cache:{period}` | Cached analytics metrics. | `redisKeys.metricsCache()` |
| `metrics:overview` | Dashboard overview cache. | `redisKeys.overviewCache()` |
| `auth:blacklist:{jti}` | Blacklisted JWT token ID (TTL = remaining token life). | `redisKeys.jwtBlacklist()` |
| `auth:refresh:{userId}` | Active refresh token JTI per user (TTL = 7 days). | `redisKeys.refreshToken()` |

All key patterns are defined in `src/config/redisKeys.js`.

## 3. Individual Schemas

### User

| Field | Type | Description |
| :--- | :--- | :--- |
| `username` | `String` | Unique, trimmed, lowercase username. |
| `email` | `String` | Unique, validated email address. |
| `passwordHash` | `String` | bcrypt hashed password (saltRounds: 12). |
| `role` | `String` | `admin` or `viewer`. Default: `viewer`. |
| `isActive` | `Boolean` | Account active status. Default: `true`. |
| `lastLogin` | `Date` | Updated on each successful login. |
| `createdAt` | `Date` | Auto-generated. |
| `updatedAt` | `Date` | Auto-generated. |

**Indexes:** `email` (unique), `username` (unique)

### ApiKey

| Field | Type | Description |
| :--- | :--- | :--- |
| `keyHash` | `String` | SHA-256 hash of the raw API key. |
| `keyPrefix` | `String` | First 8 chars of the raw key (for lookup). |
| `name` | `String` | Human-readable label. |
| `clientId` | `String` | Client identifier. |
| `scopes` | `[String]` | Allowed scopes (e.g., `read`, `write`). |
| `rateLimit` | `Number` | Custom req/min override. |
| `isActive` | `Boolean` | Key active status. Default: `true`. |
| `expiresAt` | `Date` | Optional expiry date. |
| `lastUsedAt` | `Date` | Updated on each use. |
| `createdAt` | `Date` | Auto-generated. |
| `updatedAt` | `Date` | Auto-generated. |

**Indexes:** `keyPrefix`, `clientId`

### Config

| Field | Type | Description |
| :--- | :--- | :--- |
| `key` | `String` | Unique configuration key. |
| `value` | `Mixed` | Configuration value (string, number, boolean, or object). |
| `description` | `String` | Human-readable explanation. |
| `category` | `String` | `rate_limiting`, `circuit_breaker`, `routing`, `security`, or `general`. |
| `isActive` | `Boolean` | Default: `true`. |
| `updatedBy` | `String` | Username of last admin to update. |
| `createdAt` | `Date` | Auto-generated. |
| `updatedAt` | `Date` | Auto-generated. |

**Indexes:** `key` (unique), `category`

### Backend

| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | `String` | Unique backend name. |
| `baseUrl` | `String` | Full base URL of the service. |
| `healthCheckPath` | `String` | Path for health checks. Default: `/health`. |
| `isActive` | `Boolean` | Default: `true`. |
| `weight` | `Number` | Load balancing weight. Default: `1`. |
| `timeout` | `Number` | Request timeout in ms. Default: `5000`. |
| `tags` | `[String]` | Optional grouping tags. |
| `createdAt` | `Date` | Auto-generated. |
| `updatedAt` | `Date` | Auto-generated. |

**Indexes:** `name` (unique)

### Route

| Field | Type | Description |
| :--- | :--- | :--- |
| `path` | `String` | Incoming path pattern (e.g., `/api/users/*`). |
| `method` | `String` | HTTP method or `*` for all. |
| `backendId` | `ObjectId` | Reference to Backend model. |
| `stripPrefix` | `String` | Prefix to strip before forwarding. |
| `addPrefix` | `String` | Prefix to add before forwarding. |
| `isActive` | `Boolean` | Default: `true`. |
| `requiresAuth` | `Boolean` | Whether auth is required. Default: `false`. |
| `rateLimit` | `Number` | Per-route rate limit override. |
| `priority` | `Number` | Higher = matched first. Default: `0`. |
| `createdAt` | `Date` | Auto-generated. |
| `updatedAt` | `Date` | Auto-generated. |

**Indexes:** `{ path, method }`, `backendId`

### Log Entry

| Field | Type | Description |
| :--- | :--- | :--- |
| `traceId` | `String` | Unique trace identifier. |
| `timestamp` | `Date` | Request timestamp. Default: `Date.now`. |
| `method` | `String` | HTTP method. |
| `endpoint` | `String` | Requested API endpoint. |
| `status` | `Number` | HTTP response status code. |
| `latency` | `Number` | Total processing time in ms. |
| `gatewayOverhead` | `Number` | Overhead added by gateway in ms. |
| `clientIp` | `String` | Client IP address. |
| `backendId` | `ObjectId` | Reference to Backend that handled the request. |
| `apiKeyId` | `ObjectId` | Reference to ApiKey if API key auth was used. |
| `userId` | `ObjectId` | Reference to User if JWT auth was used. |
| `errorMessage` | `String` | Error details if request failed. |
| `requestSize` | `Number` | Request body size in bytes. |
| `responseSize` | `Number` | Response body size in bytes. |

**Indexes:** `traceId` (unique), `timestamp` (TTL: 30 days), `clientIp`, `status`

### Analytics

| Field | Type | Description |
| :--- | :--- | :--- |
| `timestamp` | `Date` | Time bucket for this snapshot. |
| `period` | `String` | `minute`, `hour`, or `day`. |
| `totalRequests` | `Number` | Total requests in the period. |
| `successCount` | `Number` | 2xx status count. |
| `errorCount` | `Number` | 4xx/5xx status count. |
| `avgLatency` | `Number` | Average latency in ms. |
| `p50Latency` | `Number` | 50th percentile latency. |
| `p95Latency` | `Number` | 95th percentile latency. |
| `p99Latency` | `Number` | 99th percentile latency. |
| `throughput` | `Number` | Requests per second. |
| `backendId` | `ObjectId` | Scoped to a specific backend. |
| `createdAt` | `Date` | Auto-generated. |

**Indexes:** `{ timestamp, period }`, `backendId`

### ClientProfile

| Field | Type | Description |
| :--- | :--- | :--- |
| `clientId` | `String` | Unique identifier (IP or API key clientId). |
| `clientType` | `String` | `ip` or `apikey`. |

### Alert

| Field | Type | Description |
| :--- | :--- | :--- |
| `type` | `String` | `error`, `warning`, or `info`. |
| `message` | `String` | The alert message. |
| `source` | `String` | Module that generated it (e.g., `circuit_breaker`, `rate_limiter`). |
| `backendId` | `ObjectId` | Related backend if applicable. |
| `isRead` | `Boolean` | Default: `false`. |
| `resolvedAt` | `Date` | When it was resolved. |
| `metadata` | `Mixed` | Additional context as flexible object. |
| `createdAt` | `Date` | Auto-generated. |

**Indexes:** `type`, `isRead`, `createdAt`

| Field | Type | Description |
| :--- | :--- | :--- |
